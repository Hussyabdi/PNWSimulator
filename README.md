# PNW Simulators

Marketing website for **PNW Simulators** — a Seattle-based mobile golf simulator rental service for events across the Pacific Northwest.

## Tech Stack

- [Next.js 14](https://nextjs.org) (App Router)
- TypeScript
- CSS-in-JS (scoped `<style>` blocks per component)
- Google Fonts: Bebas Neue + Inter

## Pages

| Route | Description |
|---|---|
| `/` | Homepage — hero, specs, how it works, gallery, stats, pricing CTA |
| `/about` | About the team and service area |
| `/services` | Services overview |
| `/contact` | Contact form + location info |

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project Structure

```
app/              # Next.js App Router pages
components/       # Shared components (Navbar, Footer, AnimatedSection, etc.)
public/           # Static assets (logo, images)
```

## Deployment

Deployed on [Vercel](https://vercel.com). Pushing to `main` triggers an automatic deploy.
